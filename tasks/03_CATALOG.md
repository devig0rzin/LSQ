# Task 03 — Catalog

- busca;
- filtro por categoria/família;
- arquitetura pronta para filtros técnicos adicionais;
- cards informativos;
- query state/shareable URL quando simples e útil;
- empty state;
- mobile filter UX.

Os filtros devem trabalhar sobre seed real/curado, não criar atributos inexistentes.
