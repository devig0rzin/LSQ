# Task 01 — Design Foundation

## Objetivo
Definir uma linguagem visual LSQ específica antes de montar a Home final.

## Processo
Usar `brainstorming` + `frontend-design` + `web-design-guidelines`.

## Entregar
- rationale de direção visual;
- palette funcional;
- tipografia;
- grid/container;
- spacing/radius/border principles;
- button/link/input states;
- header/footer shell;
- 2–3 variações rápidas do hero em wireframe/composição, escolher uma;
- uma pequena página interna `/design-preview` ou story-like preview para validar tokens e componentes base.

## Gate
Parar para revisão humana antes de construir a Home final.
