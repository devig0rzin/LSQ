# LSQ XH — Beta Project Pack v0

Status: DISCOVERY / PRE-IMPLEMENTATION

Este pacote organiza o projeto antes de qualquer código de produto. O objetivo é transformar o material do cliente, referências, site atual e assets em uma fonte de verdade única para o Codex e para a proposta comercial.

## Regra principal

Nenhuma implementação deve começar antes de:
1. consolidar os materiais recebidos;
2. validar o escopo do beta;
3. validar arquitetura de informação e fluxos;
4. validar a direção visual;
5. separar o que é demonstração do que é funcionalidade real de produção.

- 02_REQUIREMENTS_MATRIX.md — requisitos confirmados, hipóteses e pendências.

- 05_BETA_SCOPE.md — o que deve existir na versão demonstrável da proposta.
- 06_TECH_ARCHITECTURE.md — arquitetura técnica candidata, sem decisão irreversível.
- 07_SKILLS_ORCHESTRATION.md — quais skills usar e em que ordem.
- 08_CODEX_PROTOCOL.md — regras para o Codex trabalhar sem sair do escopo.
