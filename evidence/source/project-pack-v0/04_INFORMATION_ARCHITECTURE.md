## Produtos
Estrutura sugerida em três níveis:
1. Família
2. Subfamília
3. Série / modelo

Filtros candidatos:
- aplicação;
- padrão/ISO;
- tamanho;
- pressão;
- material;
- tipo de conexão;
- tipo de válvula;
- compatibilidade/intercambialidade.

## Página de produto
- Nome comercial revisado
- Código / série
- Galeria limpa
- Resumo técnico
- Aplicações
- Principais benefícios
- Tabela de especificações
- Variantes / medidas
- Compatibilidade, quando aplicável
- Downloads (PDF/catálogo/desenho)
- Produtos relacionados
- CTA fixo: "Falar com especialista" / WhatsApp
- CTA secundário: "Solicitar cotação"
