# Design System Guardrails

## Tokens a definir no Gate A
O Codex deve propor e documentar antes da Home final:
- palette com 4–6 cores funcionais;
- tipografia e escala;
- grid/container;
- spacing scale;
- radius por função, não um raio único universal;
- bordas/divisores;
- estados de foco;
- motion principles;
- iconografia.

## Componentes base
- Header / Mobile nav
- Button variants
- Link
- Section heading
- Product card
- Category navigation
- Specification table/list
- Search/filter controls
- Contact CTA
- Form fields
- Footer
- 360 embed wrapper

## Acessibilidade
- contraste AA como alvo;
- foco visível;
- labels reais em formulários;
- controles touch adequados;
- navegação por teclado;
- reduced motion.
