# Rules Checklist — Gate Review

Use antes de pedir aprovação humana em qualquer gate.

- [ ] `RULES.md` foi relido para a fase atual.
- [ ] O trabalho permaneceu dentro do gate atual.
- [ ] Nenhuma informação institucional/técnica foi inventada.
- [ ] Nenhuma dependência fora do necessário foi adicionada.
- [ ] Nenhuma skill bloqueada foi executada.
- [ ] Assets originais/evidências foram preservados.
- [ ] Mobile foi revisado.
- [ ] Acessibilidade básica foi revisada.
- [ ] Não há console errors nas rotas do gate.
- [ ] Lint executado com sucesso.
- [ ] Typecheck executado com sucesso.
- [ ] Testes aplicáveis executados com sucesso.
- [ ] Build executado com sucesso.
- [ ] Copy genérica/AI-like foi revisada.
- [ ] Referências foram usadas como inspiração, não copiadas.
- [ ] `PROJECT_STATE.md` foi atualizado.
- [ ] `DECISION_LOG.md` foi atualizado quando necessário.
- [ ] A resposta final contém o formato de checkpoint definido em `RULES.md`.
- [ ] O agente parou sem iniciar o próximo gate.
