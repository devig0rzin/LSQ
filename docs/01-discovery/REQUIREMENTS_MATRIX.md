# Requirements Matrix v0

| Item | Tipo | Estado | Observação |
|---|---|---|---|
| Redesign completo da experiência | Negócio/UX | CONFIRMADO | Site atual não representa a potência percebida da empresa |
| Catálogo como função principal | Produto | CONFIRMADO | Site deve ser compartilhável com clientes |
| Conversão para WhatsApp/telefone | Conversão | CONFIRMADO | Principal ação comercial |
| Categorias de produtos | Conteúdo/IA | CONFIRMADO | Reorganizar família/subfamília/aplicação |
| Revisão de nomenclatura | Conteúdo | CONFIRMADO | Existem nomes errados/traduzidos de forma inadequada |
| Revisão PT-BR | Conteúdo | CONFIRMADO | Ortografia, capitalização, consistência técnica |
| VR / 360 fábrica | Conteúdo/Experiência | CONFIRMADO | Preservar e valorizar |
| Login/cadastro | Produto | A VALIDAR | Deve servir captura/qualificação, não bloqueio |
| CPF e CNPJ | Dados | CONFIRMADO | Ambos aceitos pelo negócio |
| CRM/planilha de leads | Operação | A VALIDAR | Cliente quer saber se lead foi contatado |
| Mascote LSquinho | Marca | A VALIDAR | Usar com contenção e propósito |
| E-commerce/carrinho | Produto | PROVÁVEL REMOÇÃO | Não é o objetivo principal descrito pelo cliente |
| Preço online | Comercial | A VALIDAR | Não assumir preço/checkout sem confirmação |
| Área do cliente | Produto | FUTURO | Pode ser fase posterior se houver valor real |
| Multilíngue | Conteúdo | A VALIDAR | PT-BR é obrigatório; EN/ZH dependem do escopo |
| SEO técnico | Aquisição | RECOMENDADO | Estrutura de categorias e produtos favorece busca orgânica |
| Analytics/conversões | Operação | RECOMENDADO | WhatsApp, telefone, formulário e cadastro devem ser mensurados |
