# User Flows

## Fluxo A — visitante já sabe o que procura
Home → Produtos → busca/filtro → Produto → Falar com especialista → WhatsApp/formulário

## Fluxo B — visitante explora por família
Home → família/categoria → catálogo filtrado → Produto → contato

## Fluxo C — visitante precisa confiar na empresa
Home → Empresa → Fábrica 360 → Produtos → contato

## Fluxo D — indicação/vendedor envia catálogo
Link direto `/produtos` ou `/produtos/[slug]` → entendimento técnico → contato

## Fluxo E — lead sem produto definido
Home/Contato → “Preciso de ajuda para encontrar” → dados mínimos → contato comercial
