# Definition of Done

Uma fase só está concluída quando:

- requisitos daquela fase foram atendidos;
- desktop e mobile foram revisados;
- navegação por teclado básica funciona;
- não há erros críticos no console;
- imagens não estouram layout;
- loading/empty/error states aplicáveis foram tratados;
- lint passa;
- typecheck passa;
- testes aplicáveis passam;
- build passa;
- `PROJECT_STATE.md` foi atualizado;
- a diferença entre conteúdo real e demonstrativo está clara.

## Demo final
Antes de enviar ao cliente:
- verificar todas as rotas;
- verificar links e CTAs;
- remover lorem ipsum;
- remover TODOs visíveis;
- remover dados fictícios que pareçam fatos;
- testar viewport mobile comum e desktop;
- testar pelo menos Chrome/Chromium;
- conferir favicon/title/metadata;
- confirmar que a primeira dobra comunica imediatamente empresa + produto + ação.
